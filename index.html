Featured Work

01
Tinto Hyperspectral Point Cloud Segmentation
TU Bergakademie Freiberg · Data Analysis & High-Performance Computing
  • Built an end-to-end benchmarking and classification pipeline for 3D geological point cloud data (lithology identification) using Python, Scikit-learn, Pandas and NumPy
  • Designed and implemented a Block-wise Exclusion Strategy to address spatial autocorrelation in geospatial data, replacing standard random cross-validation with a robust evaluation scheme
  • Executed large-scale parallel computing tasks on an HPC cluster via PBS/Torque job scheduler, processing multi-GB hyperspectral datasets efficiently
  • Documented the full pipeline, assumptions and evaluation methodology for team transparency and reproducibility
Python Scikit-learn HPC Geospatial ML Point Cloud
02
Conditional DCGAN on CIFAR-10
Academic Project · Deep Learning & Generative Models
  • Implemented a class-conditioned Generative Adversarial Network (cGAN) for controlled image generation on the CIFAR-10 dataset
  • Designed and trained generator and discriminator architectures with class embedding projections using PyTorch on GPU (CUDA)
  • Developed configurable training pipeline via YAML config files with extensive hyperparameter tuning (learning rates, weight decay, label smoothing, data augmentation)
  • Built comprehensive evaluation framework generating sample grids, latent space interpolations, confusion matrices and quantitative metrics (D(G(z)) scores, pixel statistics)
Python PyTorch Deep Learning GANs GPU Computing
