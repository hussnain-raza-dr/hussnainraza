Featured Work

Bayesian Inference for Material Strength Prediction

Research Project · Probabilistic Modeling & Uncertainty Quantification [GitHub]

  • Built a full Bayesian linear regression model for tensile strength prediction in multi-phase steel alloys as a function of temperature and carbon content, with domain-justified priors from metallurgical literature and ISO 6892-1 standards.
  • Conducted a NUTS vs. ADVI tractability study quantitatively comparing posterior quality, runtime and KL-divergence between Hamiltonian Monte Carlo and mean-field variational inference.
  • Implemented a hierarchical Bayesian model with partial pooling across alloy families (austenitic, ferritic, martensitic), demonstrating shrinkage and group-level uncertainty quantification.
  • Produced posterior predictive calibration analysis with formal credible intervals (50% and 90%) and failure probability estimation for structural reliability applications.
  • Technologies: PyMC 5, ArviZ, NUTS, ADVI, Hierarchical Bayes, Python.

Tinto Hyperspectral Point Cloud Segmentation

TU Bergakademie Freiberg · Data Analysis & High-Performance Computing [GitHub]

  • Built an end-to-end benchmarking and classification pipeline for 3D geological point cloud data (lithology identification) using Python, Scikit-learn, Pandas and NumPy.
  • Designed and implemented a Block-wise Exclusion Strategy to address spatial autocorrelation in geospatial data, replacing standard random cross-validation with a robust evaluation scheme.
  • Executed large-scale parallel computing tasks on an HPC cluster via PBS/Torque job scheduler, processing multi-GB hyperspectral datasets efficiently.
  • Technologies: Python, Scikit-learn, HPC, Geospatial ML, Point Cloud.

Conditional DCGAN on CIFAR-10

Academic Project · Deep Learning & Generative Models [GitHub]

  • Implemented a class-conditioned Generative Adversarial Network (cGAN) for controlled image generation on the CIFAR-10 dataset.
  • Designed and trained generator and discriminator architectures with class embedding projections using PyTorch on GPU (CUDA).
  • Developed configurable training pipeline via YAML config files with extensive hyperparameter tuning.
